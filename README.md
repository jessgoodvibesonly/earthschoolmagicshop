# EARTH SCHOOL — THE MAGIC SHOP

A storefront preview for EARTH SCHOOL, created by Rev. Dr. Jess Simmonds.

Black-and-gold design, a planned Egyptian Magic and Sunrider collection, browser-local wishlists, and an Ankh reward preview.

## Status

Ordering is not yet available. No payments are collected. `ANKH-DEMO` previews the reward experience and does not create a discount. Product prices, shipping, checkout links and real reward offers are still to be configured.

## Deploy to Vercel

Import this repository. Use Framework Preset **Other**, repository root as the Root Directory, no Build Command, and `.` as the Output Directory. The included `vercel.json` supplies the static deployment settings. Use a hosting plan that allows commercial websites.

## Editing

`index.html` contains the page, `styles.css` the styling, `app.js` the product catalogue and interactions, and `assets/` the images.

Product imagery is used as reference for the planned collection. Confirm final Canadian packaging, product details and approved merchandising assets before sales open. The golden Ankh artwork is illustrative and is not a product for sale.
